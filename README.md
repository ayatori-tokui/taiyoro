# TAIYORO（対よろ）

**対戦よろしくお願いします** ― スマホ2台をつないで使う、対戦カードゲーム用のチェスクロックWebアプリです。

インストール不要・ビルド不要。GitHub Pages にそのまま置くだけで動きます。

## 特徴

- 📱 **スマホ2台でP2P通信**（WebRTC / PeerJS）。QRコードを読むだけで接続
- ⏱ **大きな残り時間表示**と、手番側の緑の発光で、卓上でも一目で手番が分かる
- 🔔 手番交代時に**両端末で確認音**、押した端末は**バイブレーション**
- ↶ **1手戻す（Undo）**で押し間違いを救済。手番・消費時間・ログを巻き戻して同期
- ⏸ 一時停止／再開、リセット、ターン履歴ログ（所要時間・残り時間）
- ⏰ 時間切れ時はアラーム音と画面フラッシュで通知
- 🔄 通信が切れたら**強制一時停止**し、自動再接続。同期後に再開
- 💾 状態を自動保存。ブラウザを閉じても「前回の対局を復元する」で再開
- 🌞 画面スリープ防止（Screen Wake Lock）
- 🌤 明るくやさしい配色（OS/ブラウザのダークモード設定の影響を受けません）

## 使い方

1. **ホスト**が持ち時間（25分／30分／カスタム秒）を選んで「ルーム作成」
2. 表示された**QRコード**を**ゲスト**のスマホで読み取る（URLの共有でもOK）
3. 自動でタイマー画面に切り替わったら、ホストが「対局開始」
4. 自分の手番に画面下部の大きな「ターンエンド」をタップして手番を渡す

アプリ内の「？」ボタンにも図入りの使い方があります。

### 時間切れ（両者負け）を防ぐコツ

- 効果の確認やジャッジコールの前には、一度 **一時停止** する
- 押し間違いに気付いたらすぐ **1手戻す**
- 残り1分で表示が黄色、10秒で赤く点滅します

## GitHub Pages で公開する

1. このリポジトリをGitHubにpush
2. **Settings → Pages → Build and deployment** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` に設定
3. 表示された `https://<ユーザー名>.github.io/<リポジトリ名>/` にアクセス

> HTTPS で配信されることが、QRからの参加・Wake Lock・クリップボード機能の動作条件になります（GitHub Pages は標準でHTTPSです）。

### ローカルで試す

ファイルを直接開くのではなく、簡易サーバー経由で開いてください。

```bash
python -m http.server 8000
# → http://localhost:8000/
```

2台での通信テストは、公開URL（HTTPS）で行うのが確実です。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | UI構造、モーダル、CDNライブラリ読み込み |
| `style.css` | 配色、手番表示のアニメーション、タッチ制御 |
| `app.js` | タイマー計算、描画、Wake Lock、音・振動、状態遷移 |
| `peer-manager.js` | PeerJS接続管理、切断検知・再接続、localStorage連携 |

## 仕組み

- 通信するのは**状態遷移時のみ**（開始／ターン交代／一時停止／再開／Undo／リセット）。毎秒のタイマー値は送りません。
- 各端末は自分の `Date.now()` の差分から残り時間を計算します。受信時は端末間の時計ズレを避けるため、受信側の時計を基準にし、推定通信遅延だけ補正します。
- 送信データ: `{ type, activePlayer, timestamp, p1Remaining, p2Remaining, currentTurnNumber, turnHistory, ... }`

## 使用ライブラリ（すべてCDN）

- [Tailwind CSS](https://tailwindcss.com/)
- [PeerJS](https://peerjs.com/) 1.5.4
- [qrcode.js](https://github.com/davidshimjs/qrcodejs)
- Google Fonts（JetBrains Mono / Noto Sans JP）

## 注意事項

- PeerJS の公開クラウドサーバーと STUN サーバーを利用します。**TURN サーバーは使っていない**ため、携帯回線の種類などによっては接続できない場合があります。
- 公開サーバーは無料枠のため、将来的に仕様や可用性が変わる可能性があります。
- 対戦の公式なタイムキーピングが必要な場合は、必ず大会ルールに従ってください。
