TAIYORO の使い方

1. 接続手順

  1. ホストが持ち時間（25分／30分／カスタム秒）を選び「ルーム作成」。
  2. 表示されたQRコードをゲストのスマホで読み取る（URLを共有してもOK）。
  3. 接続に成功すると両方の画面が自動でタイマー画面へ切り替わります。
  4. ホストの画面で「先攻」（自分／相手）を選び、「対局開始」を押すと、選んだ側の手番からスタートします。

2. 画面の見かた・手番の渡し方

  • 自分の手番中だけ、画面下部の大きな「ターンエンド」をタップ。
  • 相手の手番中はボタンが無効化されます。
  • 手番が移ると両端末で「ピッ」と音が鳴り、押した端末は短く振動します。
  • 手番側は緑色に発光、待機側はグレーで控えめに表示されます。

3. 一時停止・Undo のルール

  • 一時停止／再開：どちらのプレイヤーでも操作可能。双方のタイマーが止まります。
  • 1手戻す（Undo）：直前のターンエンドを取り消し、手番・消費時間・ログを巻き戻します。押し間違い用で、履歴のある限り何手でも遡れます。
  • リセット：持ち時間を初期化し、ログも消去します（確認あり）。
  • Undo・リセット・一時停止は相手の端末にも即時反映されます。

ログ（ターン履歴）の見かた

  • P1 はホスト、P2 はゲストです（先攻・後攻とは無関係に固定）。
  • ログでは「あなた（ホスト・P1）」「相手（ゲスト・P2）」のように役割を併記します。
  • 先攻はホストが開始前に選ぶため、ターン1が P2 から始まることもあります。

4. 時間切れ（両者負け）を防ぐ推奨運用

  • 残りが1分を切ると表示が黄色、10秒を切ると赤く点滅します。
  • 0秒になるとアラームと画面点滅で通知され、そのプレイヤーの時間切れとなります。
  • 残り時間が少ない場合は、効果解決や確認の前に一度一時停止してから相談しましょう。
  • ジャッジコールや裁定確認が必要なときは、必ず一時停止してから行います。
  • ターンエンドの押し忘れ・押し間違いは、早めに Undo で戻します。
  • 終盤は「ターンエンドの宣言→タップ」を声に出して行うと、両者が同時に時間切れになる事故を避けられます。

5. 切断・再接続

  • 通信が切れるとタイマーは強制一時停止し、全画面で再接続を表示します。
  • ゲストは自動でホストへ再接続、ホストはゲストの再参加を待ちます。
  • 再接続後にホストの最新状態へ同期され、「再開」が押せるようになります。
  • ブラウザを閉じても、設定画面の「前回の対局を復元する」から続きを再開できます。
